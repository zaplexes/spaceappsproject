# Marsway app identity

The active app emblem is `marsway-logo.png`, generated with the built-in image
generation tool using the Dynamix team logo as a palette and style reference.
It combines orange Martian terrain, a purple exploration route, a location pin
and a violet compass star. The PNG has a transparent background and no embedded
wordmark. The app renders the name **Marsway** separately for accessible text.

The same emblem appears in the header and browser favicon. Both URLs use the
hosting base prefix for local development and GitHub Pages.

Earlier `martian-map-logo-v1.png` and `martian-map-favicon-v1.png` files are
archived concepts and are no longer referenced by the app.
