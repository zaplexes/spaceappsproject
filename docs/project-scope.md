# Marsway — Agreed Project Direction

Updated November 13, 2026. This decision supersedes the Jezero ancient-water mission in the original project brief and earlier planning notes. The original Portuguese brief has been removed at the user’s request. This English document defines the current scope.

## Purpose

Help astronauts decide their next destination on Mars using their starting location, adjustable interests, imagery, terrain context and visible evidence gaps. The app supports a shortlist, evidence inspection and a simulated round-trip field plan. It does not select a scientific mission for the crew.

## Agreed experience

1. Set a simulated base using the map or coordinates.
2. Compare named features within a chosen radius.
3. Begin with equal 50% study interest for every feature type. Astronauts can adjust interests and study/distance/terrain weights for their expedition.
4. Inspect a destination’s imagery, geology, source evidence and missing data before choosing it.
5. Add destinations to a round trip, define optional speed/work-time/reserve assumptions, and review distance and time estimates.
6. Save or export a draft and use the printable field plan.

Jezero and the three Perseverance sample stops remain optional worked examples. Published geology and sample descriptions stay attached to their actual sites. They do not impose a water-finding objective on other destinations.

Walking astronauts, crewed vehicles and robotic ground rovers are selectable modes. Selecting a mode does not supply validated capabilities. Feature centres and sample references remain distinct from verified observation sites.

## Scope boundaries

Ranking is preference-based decision support, not a measurement of scientific importance. Terrain remains unknown in ranking. Distance estimates are minimum surface arcs, not traversable routes. Detailed local elevation and estimated slope cover Jezero only. Hazard avoidance, verified exact drill locations, registered 3D terrain and safety certification remain unavailable.

Static GitHub Pages hosting, local drafts, validated JSON import/export and printing remain the agreed infrastructure. Accounts, a backend and new paid services are not required.
