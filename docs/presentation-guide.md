# Marsway demonstration

## Core message

**Marsway helps astronauts decide where to go next on Mars by bringing destination comparison, NASA imagery and source evidence into one planning workspace.**

The user is a simulated exploration crew. The output is a destination shortlist and a field plan; it is not a certified navigation solution.

## Demonstration narration

“Where should our crew go next on Mars? Marsway lets us set a base and compare nearby destinations. Every feature type starts with equal interest, so the crew can set priorities for its own expedition. We can inspect orbital imagery and published evidence before selecting a stop. Unknown terrain remains visible rather than becoming a reassuring score. Once we choose a destination, we can plan the return trip and export a field plan. NASA observations support the decision; the crew stays in control.”

Use a demonstration base entered by the presenter and label it simulated. Do not call it an approved landing or habitation site. Choose a search radius with catalogue results before recording; a small radius can legitimately return none.

## Visual sequence

1. **Problem:** A crew needs to choose its next destination from scattered data.
2. **Compare:** Set the simulated base, choose a radius and show a shortlist with distance and adjustable interests.
3. **Investigate:** Open one feature’s orbital preview and inspect its source evidence. Explain one useful fact and one missing input.
4. **Plan:** Add a stop, show the return leg, enter optional assumptions and export the plan.
5. **Outcome:** A transparent, reviewable decision with sources, assumptions and uncertainties.

Keep the opening map clear: Map status and location details expand only when explaining uncertainty or diagnosing imagery. Avoid opening every layer and tool during the main demonstration. Keep a recording or screenshots of the real app as backup if external imagery fails.

## Claims to use

- Uses NASA mission imagery, published observations and an IAU/USGS feature catalogue.
- Gives crews adjustable preferences and explains score components.
- Keeps missing terrain evidence unknown.
- Supports simulated round-trip distance and time estimates, local saving and export.

## Claims to avoid

- Finds water, chooses the objectively best science target, or measures science value.
- Calculates safe, traversable or obstacle-free routes.
- Offers global numerical slopes, verified sample coordinates or current Mars-wide weather.
- Has validated astronaut capabilities merely because a mobility mode is selected.
